# 小红书聚光广告组导出工具

当前版本：2.0.0

## 功能

- 在已登录的小红书聚光后台中运行，不需要填写账号、密码或 Cookie。
- 识别“竞价推广 → 标准投 → 广告组”表格。
- 自动请求全部接口分页并去重采集“广告组”和“广告组ID”。
- 捕获第一页列表请求后，直接调用同一接口逐页采集，不再操作网页滚动条或页码。
- 读取页面“合计 N 条记录”作为目标值；只有采集数与目标值完全一致时才自动导出。
- 直接下载 `.xlsx` 文件；ID 按文本保存，避免 Excel 改写。
- 同时监听页面接口中的 `campaignGroupName`、`campaignGroupId` 字段，减少因页面样式变化造成的漏采。
- Excel 包含账号、广告组、广告组ID、广告组状态和导出时间。
- 账号取右上角账号名称。
- Excel 不包含账号ID和数据日期；导出时间使用下载时的电脑本地时间。

## 安装（Chrome / Edge）

1. 解压本工具包。
2. Chrome 打开 `chrome://extensions/`；Edge 打开 `edge://extensions/`。
3. 打开右上角“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择本文件夹 `xhs-adgroup-exporter`。
5. 安装后刷新一次已经打开的聚光页面。

## 使用

1. 登录聚光后台，进入“竞价推广 → 标准投 → 广告组”。
2. 点击浏览器工具栏中的“小红书聚光广告组导出”。
3. 点击“采集全部并校验后导出 Excel”。采集时请保持该页面在前台，不要切换分页或关闭页面。
4. 浏览器会下载名为 `小红书聚光_广告组_日期时间.xlsx` 的文件。

每次全量采集都会清空上一次的临时结果，从零开始重新采集，因此数量不会继续累加。若采集数量未达到页面显示的总记录数，工具会停止自动导出并明确显示缺少的条数，避免生成残缺文件。

“仅采集当前页”和“导出已采集数据”保留为人工排查功能，不执行全量完整性保证。

若网站更新后无法翻页，请点击“导出分页诊断信息”，把生成的 JSON 文件发给开发者。该文件记录分页控件结构和列表接口地址，不包含账号密码或 Cookie。

## 数据与权限

扩展只在 `https://ad.xiaohongshu.com/*` 下运行。数据仅保存在当前页面内存中，关闭或刷新页面即清空。扩展不会上传数据，也不会读取或保存账号密码。

## 页面改版后的排查信息

如果自动翻页或采集失败，请在开发者工具 Network 中选择返回广告组列表的请求，提供以下任一项即可适配：

- 右键请求 → Copy → Copy as cURL（可先删除 Cookie/Authorization 等敏感值）；或
- 请求的完整 URL、Request Payload，以及分页字段名；或
- 导出的 HAR 文件（分享前删除敏感请求头）。

请勿通过聊天发送账号密码。
