# 常见问题与问题反馈

先判断卡在哪一步，再提供别人能够复现的问题信息。

## 先判断应该找谁

| 卡在哪里 | 先检查 | 找谁协助 |
| --- | --- | --- |
| 智采登录不了 | 邮箱密码、审核状态，以及页面提示 | 管理员。 |
| 工具显示未授权 | 是否已开通该工具 | 管理员。 |
| 没有平台账号或验证失败 | 平台、客户链接、连接状态及具体错误 | 没有账号可自行新增；自己的账号按连接说明更新，他人账号需联系该账号维护人。 |
| 文件或输入被拒绝 | 必需列、日期、工作表及错误提示中的行号 | 先按工具说明修正，仍有问题再反馈。 |
| 任务失败或结果不符合预期 | 任务编号、查询条件、失败明细 | 通过需求中心提交运行问题。 |

## 在页面里怎么反馈

1. 普通成员打开“需求中心”：想增加新功能选“新增取数工具”，已有工具想调整选“改进现有工具”，本次任务报错选“运行问题”。
2. 工具页面的“对此工具提需求”可带上关联工具；运行记录中的“反馈问题”可关联对应任务。
3. 写清做了什么、原本想得到什么、实际发生了什么。工具名、任务编号和报错文字尽量完整。
4. 需要截图或样例文件时，最多上传 3 个，每个小于 10 MB。支持 PNG、JPG/JPEG、WebP、PDF、CSV 和 XLSX；先去掉密码、Cookie 和无关敏感内容。
5. 提交后进入“我的需求”查看状态和补充说明。

## 一份能定位问题的填写例子

以下是虚构示例，可照着结构填写，但请替换成你的实际情况：

| 信息 | 填写示例 |
| --- | --- |
| 标题 | 笔记封面与内容：试跑 3 条，其中 1 条封面未下载。 |
| 操作步骤 | 上传 .xlsx → 选择 Sheet1 → 试跑前 3 条 → 开始采集。 |
| 希望得到什么 | 3 条笔记的正文与封面。 |
| 实际发生什么 | 任务部分完成，第 2 条有正文但没有封面，错误文字为“请填写实际报错”。 |
| 定位信息 | 发生时间、任务编号、对应工具；附去除敏感内容后的截图或最小样例。 |

任务编号可在结果区“任务”后或运行记录中找到；请从你自己的任务复制，不要用客户 ID、笔记 ID 代替。新增工具需求还应提供数据在哪个平台、哪个页面和需要哪些字段。

## 无法进入页面或迟迟没有结果

### 登录后一直转圈怎么办？

先不要连续提交登录。观察是否已跳到工具中心，若持续等待，可刷新一次并记下发生时间；仍无响应时联系管理员，说明浏览器、提示和大致等待时长。此前出现过登录成功但页面加载较慢的情况，原因尚未确定，不能一概当成密码错误。

### 登录不了，进不去需求中心怎么办？

通过现有联系渠道找管理员，提供注册邮箱、发生时间和提示截图；不发送密码或 Cookie。

### 提交需求后会马上上线吗？

以需求详情中的状态和处理说明为准。需要补充时在详情中追加，同一问题不要重复建多条；提交不代表已承诺完成时间。
