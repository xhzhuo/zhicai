# 下载结果与历史记录

页面只是预览；完整文件要下载，历史任务要按创建时间查找。

## 下载按钮在哪里

1. 任务结束后，在右侧结果区查看状态及失败明细。
2. 点击页面实际出现的下载按钮：例如“下载结果 Excel”“下载完整结果”或“导出已采集数据”。不同工具按钮文字可能不同。
3. 笔记工具如果有成功保存的封面，还会提供“下载封面素材包”。需要原图时另外下载这份 ZIP。
4. 下载保存位置由浏览器决定。找不到文件时可在 Chrome 或 Edge 按 Ctrl+J 打开下载列表，再查看文件所在文件夹。

CSV 可以用 Excel 打开；.xlsx 是 Excel 工作簿；ZIP 是打包文件，解压后再查看里面的表格和素材。任务未结束、没有数据或文件未生成时，下载按钮可能不可用。

## 下载后先核对这四项

| 检查项 | 怎么看 |
| --- | --- |
| 是不是这次查询 | 核对工具、平台账号、输入内容和查询日期，避免打开旧文件。 |
| 是不是完整文件 | 页面通常仅预览前 30 行。下载文件的行数可以更多，不能只保存页面预览。 |
| 有没有未完成项 | 看任务是否部分完成，展开失败明细；笔记表还要看每行“下载状态”和“错误信息”。 |
| 字段和工作表是否符合需要 | 多工作表的 Excel 要逐张看；关键词推荐与每日搜索量不是同一种数据，素材包也不同于 Excel 内嵌预览。 |

输入条数和结果行数不一定相等：一个词根可以扩出很多关键词，一条输入也可能没有数据或处理失败。应结合该工具的“下载后怎么看”判断。

## 隔天怎么找回文件

1. 进入“运行记录”，先按平台和工具缩小范围，再按“创建时间”选择今天、近 7 天或其他范围。
2. 这里筛选的是你点击开始、创建任务的日期，不是你要查询的数据日期。例如今天查询上个月的数据，应先按今天的任务查找。
3. 通过账号、创建时间和任务编号找到记录，点击“查看”，核对详情后再下载。
4. 找不到时先重置筛选，并确认登录的是当时创建任务的智采账号。

## 结果和文件常见问题

### 为什么下载后只有表头或没有想要的记录？

先核对工具、账号和查询范围，再看平台是否确实返回 0 条或存在失败。只有表头不代表找到了业务记录。

### 同团队同事能直接下载我的结果吗？

同团队共同使用平台连接，不代表个人任务也会共享。你使用自己的智采登录账号查看和下载自己创建的任务；同团队的其他普通成员不能直接下载你的个人任务结果。

### 结果文件找不到或无法下载怎么办？

先确认任务已结束和页面有下载入口，再看浏览器下载提示。若提示结果文件不存在，记录任务编号反馈，不要把重复采集当成唯一处理方式。
