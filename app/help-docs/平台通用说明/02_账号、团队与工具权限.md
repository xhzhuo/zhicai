# 账号、团队与工具权限

分清自己的智采登录账号、所属团队和可以使用的工具。

## 先分清两种账号

| 名称 | 是什么 | 什么时候用 |
| --- | --- | --- |
| 智采登录账号 | 你自己的邮箱和密码 | 进入智采、找回自己的任务与需求。 |
| 平台账号 | 团队在智采中保存的聚光或灵犀连接，通常以别名显示 | 工具中的“使用账号”下拉，用它决定去哪个客户或平台取数。 |

“团队”是你在智采中的分组，不是广告平台里的客户。登录智采不等于已经登录聚光；同团队能共享平台连接，也不等于每个人都能用所有工具。

## 普通成员需要做什么

1. 注册时选择自己的团队。不确定选哪个时，先向管理员确认，不要随意选其他团队。
2. 告诉管理员需要使用的工具名称，等待审核和授权。
3. 登录后进入工具，检查“使用账号”下拉中是否有正确的平台连接；没有时可进入“平台账号”自行新增并完成配置。
4. 改密码时点右上角“改密”，填写当前密码和至少 12 位的新密码，保存后重新登录。共用电脑使用完毕点“退出”。

你可以在“平台账号”中自行新增聚光或灵犀账号，填写页面链接、保存 Cookie 并验证。自己新增的账号由自己维护；已有账号若没有“配置”按钮，不能直接修改，可按需新增自己有权使用的账号。

## 遇到权限问题找谁

| 你看到的现象 | 怎么处理 |
| --- | --- |
| 同事能用，我不能用 | 联系管理员核对个人工具权限，不要借用同事的登录账号。 |
| 工具尚未接入 | 等待功能开放。 |
| 智采个人登录账号待审核、被拒绝或已停用 | 这是用邮箱登录智采的个人账号状态，请联系管理员核对。它与聚光、灵犀的平台连接不同，更新平台 Cookie 不能解决这类登录问题。 |
