# 运行任务与查看进度

点开始后先看状态，结束后再下载；不需要一直停留在运行页面。

## 怎样确认已经提交

1. 填写好账号、文件和查询条件，点击“开始采集”。
2. 看到任务编号及“等待运行”或“运行中”，说明任务已创建，不要再点一次开始。任务编号是定位这次取数的标识，不是广告平台账号编号。
3. 如果页面只显示输入错误或队列提示，没有新任务，先按提示处理；“按钮点过了”不等于提交成功。
4. 记下工具名称和任务创建时间；离开后可到“运行记录”查找。

## 每个状态下一步做什么

| 状态 | 你可以怎么做 |
| --- | --- |
| 等待运行 | 任务在排队，等待即可；不需要重新提交。 |
| 运行中 | 看当前阶段和已处理数量。扩词后总数增加可能是正常过程；不要仅因进度变化就重复开始。 |
| 全部完成 | 先核对结果范围和需要的字段，再下载文件。 |
| 部分完成 | 展开失败明细或查看逐条状态；已成功部分可按页面入口下载，缺失部分再决定是否重跑。 |
| 运行失败 / 已停止 | 看错误或结束原因。只有页面提供文件下载时才有可交付文件，不要当成完整成功。 |

## 离开页面、取消或重跑

1. 只想切换页面时，直接去其他页面；刷新或离开运行页不等于取消任务。之后从“运行记录”点击“查看”返回。
2. 确实不需要继续时，在任务详情进度区点“取消任务”；等待状态变为结束，正在执行的操作可能需要收尾。
3. 需要重跑时，先确认原任务已结束，检查失败原因，再修正账号或输入条件。建议只重跑需要补充的部分，避免重复工作。

不要用关闭浏览器的方式判断任务是否停止，也不要看到等待就再提交一份。

## 等待或报错时怎么办

| 提示或现象 | 先做什么 |
| --- | --- |
| 队列已满 / 已有排队或运行任务 | 先等现有任务结束；不需要的任务可在详情中取消。 |
| 提交过于频繁 | 按页面提示稍后再试，不要连续点击。 |
| 进度暂时不变 | 先看当前阶段，平台响应和文件生成可能需要时间；持续异常时保留任务编号反馈。 |
| 任务超时 | 看结束原因，减少输入数量或日期范围后再试；不要直接把原任务连续提交多遍。 |
| 存储空间不足 / 服务正在停止 | 暂缓提交，联系管理员，不需要反复修改业务文件。 |
