# 首次使用

第一次使用，从注册、选工具到下载结果，按顺序完成即可。

## 先弄清楚要准备什么

智采帮你从小红书等平台整理数据，再下载到电脑。你不用编写代码，按工具页面填写条件或上传文件即可。

| 准备项 | 你需要做什么 |
| --- | --- |
| 智采登录账号 | 用自己的邮箱注册并登录，不是小红书或广告平台账号。 |
| 团队与工具权限 | 注册时选择自己的团队，等待管理员审核并开通需要的工具。 |
| 取数资料 | 看工具要求准备词根、查询日期或 Excel 文件；先阅读对应工具的“开始前准备”和“每个选项怎么填”，需要查找编号时再看资料获取步骤。 |
| 平台连接（部分工具需要） | 聚光、灵犀工具需要团队已有的可用连接。笔记封面与内容不需要这两类账号。 |

## 注册后怎么进入工作台

1. 打开智采登录页，已有账号选“登录”，用注册邮箱和密码进入。第一次使用选“注册”，按页面填写邮箱、密码并选择正确的团队。
2. 提交注册后联系管理员审核，并说明自己需要哪些工具。如果没有可选团队，先联系管理员创建团队。
3. 审核并获得工具权限后重新登录，进入“工具中心”。标记“可用”代表功能已接入；你的账号是否能打开，还取决于个人权限。
4. 找到工具后先打开“使用说明”，按“开始前准备”和“每个选项怎么填”整理资料；行业编号等另有资料获取步骤，按需查看。

## 照着做完第一次取数

1. 在“工具中心”找到目标工具，点击“配置采集”。
2. 需要账号时，在“使用账号”中选择对应客户；需要文件时，上传工具要求的 Excel。核对查询日期和必填项。
3. 第一次先用少量数据。只有工具提供试跑或文件检查时才选择这些方式，其他工具可先减少词根或缩短日期范围。
4. 点击“开始采集”，看到“等待运行”或“运行中”后，不要重复提交。
5. 结束后先看状态与失败明细，再下载文件。以后从“运行记录”点击“查看”，可以回到这次任务。

例如：用笔记封面与内容工具时，可以先准备 3 条笔记清单，选择试跑前 3 条；这不代表所有工具都有“试跑”选项。

## 卡住时先看这里

### 注册了但不能登录？

看页面是否提示智采个人登录账号待审核或已停用；请管理员核对该登录账号的状态。忘记密码时联系管理员，当前没有自助找回入口。

### 工具写着可用，但按钮显示未授权？

“可用”是功能状态，“未授权”是你的访问权限。请管理员开通该工具。

### 能打开工具但不能开始？

先看页面提示：可能缺少账号、文件或必填项。需要连接的工具可到“平台账号”核对，文件问题按提示修正后重新上传。
