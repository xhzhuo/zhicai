# 推荐词每日搜索量

先按词根获取推荐词，再查询去重后关键词在指定日期内的每日搜索量。

## 能帮你做什么

该工具包含扩词和每日查询两个阶段。输入的是词根，最终查询对象是平台返回的推荐关键词，不能将它理解为只查输入词根自身的搜索量。

## 开始前准备

- 需要“推荐词每日搜索量”权限及本团队的聚光账号。
- 准备词根和查询起止日期。当前工具每次支持 1～30 个词根，超过时拆成多批；各批使用同一日期范围，方便后续核对。
- 推荐词越多，请求越多，首次使用建议先用少量词根与较短日期范围。

## 输入资料怎么获取

输入的词根准备方法与“关键词推荐”相同：直接填写基础词，或从 Excel 单列复制，不需要查找编号。

| 需求 | 应该使用的工具 |
| --- | --- |
| 想拿到推荐词、月搜索指数和词根内排名 | 使用“关键词推荐”。 |
| 想知道推荐词每天有多少搜索量 | 使用本工具，输入词根并选择查询日期。 |
| 只想查某个指定词自身的每日搜索量 | 当前流程会先扩词，不能保证只查询这个指定词。 |

流程示例（虚构）：输入“防晒” → 平台返回“通勤防晒”“户外防晒”等推荐词 → 工具查询这些推荐词在所选日期内的每日搜索量。示例不保证实际返回这些词。

第一次建议填 1 个词根、选近 7 天。下载后先看 keyword（关键词）、date（日期）和 searchNum（搜索量）三列，确认实际查询对象及日期。账号配置方法见“平台账号与连接状态”。

## 每个选项怎么填

| 参数 | 填写方式 |
| --- | --- |
| 使用账号 | 选择对应客户的聚光账号。 |
| 词根列表 | 每行一个，可导入 CSV / TXT；重复词根会合并；每次最多 30 个，超过时分批填写。 |
| 查询日期 | 填写开始和结束日期，包含两端；开始不得晚于结束，单次最多 91 天。 |
| 快捷日期 | 可选择近 7 天、近 14 天或近 30 天，提交前检查实际显示的起止日期。 |

## 开始操作

1. 确认账号，填写或导入词根列表。
2. 设置起止日期，检查日期范围。
3. 点击“开始采集”；先获取各词根的推荐词，再将推荐关键词合并去重。
4. 等待每日数据查询完成，检查失败明细，下载结果 CSV。

## 下载后怎么看

| CSV 字段 | 含义 |
| --- | --- |
| keyword | 实际查询的推荐关键词。 |
| date | 平台返回的统计日期。 |
| searchNum | 该关键词在对应日期的搜索量，沿用平台返回口径。 |

同一个推荐词来自多个词根时，只查询一次。输出不包含原词根映射，也不保留推荐词的月搜索指数和排名；需要这些信息请另用“关键词推荐”。

## 常见问题

### 为什么结果中有我没有逐行输入的关键词？

工具会先扩词，结果展示的是推荐词的每日数据。

### 为什么进度总数会增加？

扩词完成后，去重后的关键词加入处理总数，属于正常流程。

### 为什么部分日期没有行？

工具保留接口实际返回的行，不为未返回的日期补零。请核对日期范围及失败明细。

## 使用限制

30 个来自智采当前程序设置的单次提交上限，不代表平台官方公布的限制。多个词根可能扩出同一个关键词；分批下载的结果若需要合并，应按 keyword 和 date 核对重复记录。

- 一次 1～30 个词根，日期跨度最多 91 天。扩词数量越多，耗时越长。
- 关键词阶段失败会记录关键词；扩词阶段失败会记录词根。两类失败都可能影响最终覆盖。
- 查询结果仅反映当前平台返回，空缺不自动等于搜索量为 0。
