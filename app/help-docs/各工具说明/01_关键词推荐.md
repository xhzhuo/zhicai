# 关键词推荐

按词根获取聚光推荐关键词，查看月搜索指数及词根内排名。

## 能帮你做什么

从聚光获取推荐关键词，并按月搜索指数从高到低排列，适合扩词及整理关键词清单。只获取包含你输入词根的推荐词；“词根”就是用来查找相关词的基础词。

## 开始前准备

- 需要“关键词推荐”工具权限，以及本团队可用的聚光账号。
- 确认账号 Cookie、目标客户页面链接已配置；连接问题请先到“平台账号”核对。
- 当前工具每次支持 1～30 个词根，每行一个，可直接从 Excel 单列复制。超过 30 个时分批运行：第 1 批填前 30 个，第 2 批填剩余词根。

## 输入资料怎么获取

“词根”就是你希望围绕它寻找相关关键词的基础词，不需要到浏览器后台找。比如想了解防晒相关词，可以先填“防晒”；这只是填写示例。

| 你准备的内容 | 怎么放进工具 |
| --- | --- |
| 手头只有几个词 | 在词根列表逐行填写，一个词根占一行。 |
| 已有 Excel 清单 | 选中一列词根单元格，复制后粘贴到词根列表；不要一起复制表头。 |
| 需要文件导入 | 先用“下载单列模板”查看格式，保持单列词根，保存为 CSV 或 TXT 后导入。 |

输入示例：“防晒”占第一行，“敏感肌防晒”占第二行。工具会分别返回包含相应词根的推荐词；是否包含词根本身，以平台返回为准。CSV 是可以用 Excel 打开的表格文件。

账号怎么准备：请阅读“平台通用说明 → 平台账号与连接状态”，其中包含客户页面链接和 Cookie 获取步骤。

## 每个选项怎么填

| 参数 | 填写方式 |
| --- | --- |
| 使用账号 | 选择本次查询对应的聚光客户账号。 |
| 词根列表 | 填写 1～30 个词根；工具会去除词根前后的空格，并将重复词根合并为一个。换行、中英文逗号均会分隔词根。 |
| 导入与模板 | 可导入 CSV / TXT，或下载单列模板后填写。请将词根按单列逐行整理。 |

例如可分别输入“防晒”“敏感肌防晒”。这是格式示例，不代表推荐投放词。此工具没有查询日期或推荐数量配置项。

## 开始操作

1. 打开工具并确认使用账号。
2. 粘贴词根，或导入 CSV / TXT；检查有效输入及重复项提示。
3. 点击“开始采集”，等待各词根处理结束。
4. 检查失败明细，并下载完整 CSV（可用 Excel 打开的表格文件）；需要每日数据时另用“推荐词每日搜索量”。

## 下载后怎么看

| CSV 字段 | 含义 |
| --- | --- |
| 日期 | 本次处理时生成的日期，不是用户指定的统计周期。 |
| 词根 / 关键词 | 本次输入及平台返回的推荐词。 |
| 月搜索指数 | 聚光返回的月搜索指数，数值含义以聚光页面说明为准。 |
| 词根内排名 | 按该词根结果的月搜索指数降序编号，从 1 开始。 |

排名由工具按指数排序生成，不代表平台的广告排名。同一关键词可能出现在不同词根的结果里。

## 常见问题

### 某个词根失败，其他结果还能用吗？

可下载已成功返回的结果，并在失败明细查看对应词根及原因。

### 为什么与平台页面看到的数量或顺序不同？

结果以本次账号和平台接口返回为准，工具按月搜索指数重新排序；请核对客户账号及查询时间。

## 使用限制

30 个来自智采当前程序设置的单次提交上限，不代表平台官方公布的限制。需要处理更多词根时，请拆分为多批提交。

- 一次最多 30 个有效词根；扩词量以平台返回为准，没有完整覆盖所有相关词的保证。
- 月搜索指数不等于每日搜索量，不能将它直接拆分成各日数据。
- 本工具只获取数据，不执行广告创建或投放。
