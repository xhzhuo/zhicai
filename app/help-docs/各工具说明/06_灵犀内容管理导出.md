# 灵犀内容管理导出

## 这个工具用来做什么

按产品和查询日期，从小红书灵犀“内容管理”获取笔记表现，自动读取全部分页并导出 Excel。适合查看某个产品关联的笔记、种草消耗、曝光和阅读表现。

## 开始前准备

准备一个已配置 Cookie 的灵犀账号，该账号需有对应品牌和产品的访问权限。确定要导出的产品与查询日期。

## 输入资料怎么获取

在智采选择对应客户的灵犀账号，点击“读取授权产品”，自动关联当前品牌并展示产品列表，再搜索、勾选本次要采集的产品。灵犀页面位置为“小红书灵犀 → 洞察 → 内容 → 内容管理”。

读取使用智采所选账号保存的 Cookie，与你电脑浏览器的登录状态相互独立。读取失败时检查所选灵犀账号的连接和产品权限，再重试。

## 每个选项怎么填

- 使用账号：选择对应客户的灵犀连接。
- 选择产品：读取后按名称或 SPU ID 搜索并勾选 1～20 个产品。搜索不会清除已选产品；达到20个后，先取消一个再选其他产品。“清空已选”会取消全部勾选。
- 查询日期：选择开始和结束日期，这是灵犀接口的统计查询范围，结果可包含更早发布的笔记。

品牌由读取结果自动关联，无需填写品牌编号或产品编号。切换账号后需要重新读取并选择产品。

## 从开始到下载

1. 选账号，读取授权产品，勾选需要的产品（最多 20 个）。
2. 核对日期和产品，点击“开始采集”。
3. 进度会显示当前产品、页码和已读取条数。可以取消任务。
4. 完成后查看状态、数据预览和失败原因，再下载 Excel；以后可在运行记录中找回。

## 下载结果怎么读

“内容数据”包含产品名称、SPU ID、查询日期、笔记及作者信息、种草消耗、CTR（全部流量）、曝光量、阅读量（全部流量）、笔记链接和封面链接。“采集记录”列出每个产品的接口总数、导出条数、状态与失败原因。

同一笔记关联不同产品时分别保留。标题等平台缺失字段保持空白，不补造数据。封面只导出链接，不下载或内嵌图片。



明细末尾增加“记录提示”“同产品笔记ID出现次数”“来源页码”“页内序号”；采集记录增加唯一笔记数、重复笔记ID数、涉及重复的记录行数和数据提示。同一产品中的重复行全部保留，不去重、不合并指标。

## 遇到问题怎么处理

同一产品内笔记 ID 重复时，不再使整个产品失败。工具保留平台返回的每一行及其原始指标，在所有重复行添加“记录提示”，并在采集记录中列出唯一笔记数、重复 ID 数和涉及重复的记录行数。不要直接把重复行的指标相加；请核对原始记录。

缺少笔记 ID、分页提前结束、总数变化或整页内容完全重复时，该产品仍判定失败，不导出不完整的产品明细；其他成功产品保留。成功的空结果会导出表头与采集记录。

读取失败时检查所选灵犀账号的连接和产品权限。开始按钮不可用时查看按钮上方的具体原因；未勾选时提示“请至少选择 1 个产品”。

## 使用限制

每次最多 20 个产品、100000 条结果，单个产品最多 100000 条，实际还受平台权限、响应和任务时限影响。每页最多请求 100 条，按接口实际返回的每页条数继续翻页。任务串行取数，不修改笔记或投放状态。
