# 笔记封面与内容

上传笔记清单，整理标题、作者、正文与首张封面，并保留逐条处理状态。

## 能帮你做什么

根据上传清单读取小红书笔记公开页面，输出笔记信息、封面预览及可下载的原图素材。无需配置聚光或灵犀账号。

## 开始前准备

- 需要“笔记封面与内容”工具权限。
- 准备不超过 20 MB 的 .xlsx 文件，第一行为表头，目标工作表须各有且仅有一列“笔记id”和“笔记链接”。
- 每条记录同时填写 ID 与链接；两列都空的行会跳过，只缺一项会拒绝文件。单次须为 1～200 条记录。
- 尽量保留完整分享链接及其参数；仅有笔记 ID 或不完整链接可能无法取得内容。

## 每个选项怎么填

| 参数 | 填写方式 |
| --- | --- |
| 上传笔记文件 | 仅支持 .xlsx，不支持直接上传 CSV、旧版 .xls 或粘贴链接清单。 |
| 数据工作表 | 上传后选择同时包含两列必需字段的工作表；缺列的工作表不可选。 |
| 正式处理全部链接 | 处理所选工作表中的全部有效记录。 |
| 试跑前几条 | 按文件顺序处理前 N 条，N 为 1～200，默认 3；整个文件仍须先通过结构及记录校验。 |
| 仅检查文件，不联网 | 检查输入，不抓取笔记内容或封面；不用于验证链接在平台上是否可访问。 |

## 开始操作

1. 整理 Excel 表头和记录，上传文件，确认文件检查提示。
2. 选择目标工作表及运行方式；初次建议先试跑少量记录。
3. 开始处理，在结果区查看当前阶段与成功、部分成功、失败数量。
4. 任务结束后下载结果 Excel，检查“下载状态”和“错误信息”。
5. 如有成功下载的封面，另点“下载封面素材包”，获得结果表和封面原图 ZIP。

## 下载后怎么看

| 工作表 / 字段 | 含义 |
| --- | --- |
| 笔记数据 | 结果 Excel 的工作表，每条笔记保留一行处理结果。 |
| 笔记id / 笔记链接 | 原始输入记录，便于回查。 |
| 笔记标题 / KOL名称 / 笔记内容 | 实际获取的标题、作者昵称与正文。 |
| 封面链接 / 下载文件 / 封面图片 | 封面地址、保存文件名和 Excel 内嵌预览；素材包保留原图。 |
| 下载状态 / 错误信息 | 逐条处理结果及未完成原因，不能只看是否有标题。 |

仅检查文件模式不生成真实抓取内容；素材包只在至少有封面成功保存时提供。

## 常见问题

### 表头明明有两列，为什么仍报错？

确认它们在所选工作表的第一行，名称与“笔记id”“笔记链接”一致且各出现一次；不要重复放置同名列。

### 有正文却没有封面怎么办？

查看该行状态与错误信息。页面内容和图片下载分别可能失败，不应将部分成功当作全部成功。

### 笔记在 App 中能看，为什么工具失败？

工具读取公开页面，App 登录状态不代表服务器能访问。私密、失效、要求登录或受平台限制的页面仍可能失败。

## 使用限制

- 链接须为 HTTPS，当前接受 www.xiaohongshu.com、xiaohongshu.com 和 xhslink.com 域名；通过格式校验不保证可抓取。
- 仅获取首张封面，不批量下载整篇笔记的所有图片或视频。
- 单条有处理时限；大图可能保留原图但不嵌入 Excel 预览。平台限制、图片异常或资源配额均可能影响结果。
- 不承诺每条链接都成功；失败或部分成功应按逐条原因处理。
