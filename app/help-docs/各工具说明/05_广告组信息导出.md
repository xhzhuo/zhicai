# 广告组信息导出

自动读取所选聚光账号的全部广告组分页，导出固定字段的 Excel。

## 能帮你做什么

用于整理聚光广告组名称、ID 和状态。工具通过平台接口自动读取全部分页，无需手动翻页，也无需上传广告组清单。

## 开始前准备

- 需要“广告组信息导出”权限及本团队的聚光账号。
- 确认账号配置中的页面链接对应目标客户，并已保存适用的 Cookie。
- 需要指定统计日期时提前确认起止日期；不填则使用今天。

## 输入资料怎么获取

此工具不需要你查找或填写广告组 ID。只需先确认智采里的聚光账号对应哪个客户，工具会获取它能访问的广告组。

1. 在电脑浏览器登录聚光（ad.xiaohongshu.com），先进入需要取数的客户账号；如果看到客户列表，先点击目标客户，不要停留在列表页。
2. 检查聚光页面当前显示的客户名称，再点击浏览器地址栏，复制完整网址。网址应属于 ad.xiaohongshu.com 且含 vSellerId= 后的一段客户标识。
3. 在智采“平台账号”新增或配置对应账号，将完整网址粘贴到“页面链接”；这里不用单独提取或手输 vSellerId。
4. 按“平台账号与连接状态”中的 Cookie 获取步骤完成连接，保存后验证。然后回到工具选择该账号。

第一次可以日期留空，先看广告组数量提示，再开始导出。文件中的“账号”是智采账号别名；广告组 ID 是输出内容，不是开始前要准备的输入。

## 每个选项怎么填

| 参数 | 填写方式 |
| --- | --- |
| 使用账号 | 选择需要导出广告组的聚光客户账号。 |
| 开始日期 / 结束日期 | 可同时留空，默认北京时间当天；指定时必须两项都填，开始不能晚于结束。 |
| 广告组数量提示 | 选择账号或修改日期后会自动查询数量；出错时检查提示。提示是当前预查询结果，实际导出仍会重新读取。 |

日期会传给广告组查询，但导出文件不包含花费、曝光、点击或转化等效果指标；当前没有按广告组状态或名称过滤的选项。

## 开始操作

1. 选择聚光账号，确认客户范围。
2. 按需填写起止日期，等待广告组数量提示。
3. 点击“开始采集”，等待工具读取全部分页并生成文件。
4. 确认任务结束和导出状态，点击“导出已采集数据”下载 Excel。
5. 打开“广告组信息”工作表，核对账号、数量及 ID。

## 下载后怎么看

| Excel 字段 | 含义 |
| --- | --- |
| 账号 | 智采中选择的平台账号别名，不是平台登录名或客户 ID。 |
| 广告组 | 平台返回的广告组名称。 |
| 广告组ID | 广告组唯一标识，按文本导出以保留完整数字。 |
| 广告组状态 | 平台提供的状态名称，或依据启用值显示“有效 / 暂停”。 |
| 导出时间 | 北京时间的文件生成时间。 |

工作表名为“广告组信息”。平台返回 0 个广告组时，可生成仅含表头的文件。

## 常见问题

### 为什么界面数量提示与导出数量不一样？

数量提示和正式导出发生在不同时间。先核对客户与日期；若采集期间平台总数发生变化，工具会报错，需待列表稳定后重试。

### 提示重复 ID、分页提前结束或未知状态怎么办？

工具在核对数据完整性时发现异常，会停止生成正常结果。检查错误提示，确认平台列表稳定后重试；持续出现时附任务编号反馈。

### 能直接导出广告组效果指标吗？

当前只导出固定 5 列信息，统计日期不会让文件增加效果指标。

## 使用限制

- 单次广告组上限为 100000 条，受平台响应与任务时限约束。
- 采集中总数变化、重复 ID、缺少名称/ID或未知状态会导致失败，不能把失败结果当作完整清单。
- 只读取所选账号当前可访问的广告组，不修改广告组或投放状态。
